# Click casting bindings are saved per character

The rings are saved for the account, each character using what it has, but a character's bindings
are its own: the same combination means a heal on one class and something else on another, and
sharing them would make clashes across classes the normal case. Within a character a binding still
only works while the character has its action, so one combination can do different things in
different specializations without any per-specialization lists.
